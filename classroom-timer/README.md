# Classroom Timer

A simple browser timer for classroom activities. Set a duration, start the countdown, and project the page so students can see the remaining time.

## Use it

Open `index.html` directly in a browser. No installation or internet connection is required for the timer itself.

- Choose a quick preset or enter minutes and seconds.
- Select **Start timer** to begin.
- Use **Space** to start or pause, and **Reset** to return to the selected duration.
- The fullscreen button is useful when projecting the timer.
- Select **Student view** to open a synchronized, minimal overlay in a separate browser window. Move that window to the top-right corner of the activity screen.

The overlay's page background is transparent. Browser window transparency is controlled by the browser and operating system, so for a truly see-through floating window use a presentation or browser tool that supports transparent windows.
