Week 1 · Introduction to Virtual Assistants

Slide 1: What is a Virtual Assistant?

Definition: Software applications designed to interact with users via natural language (text or speech) to satisfy tasks or answer inquiries.

3 Primary System Architectures

  1. Event Classifiers
    Single-input categorization engines
    Example: spam filtering, support ticket routing

  2. Command Interpreters
    Action-oriented, usually single-turn systems
    Example: “Turn off the living room lights.”

  3. Conversational AI
    Multi-turn dialogue agents that maintain context

  • 🏷️ Classifier: categorize
  • ⚡ Command: execute
  • 💬 Conversational AI: track context and respond across turns

Slide 2: Primary Enterprise Use Cases

  • Self-Service Automation

  • Agent Assist

Week 2 · Building Your First Virtual Assistant

Slide 1: Core Mechanics — Intents and Entities

  • Intents = user’s goal/action (verb-focused)
    Examples: #Check_Balance, #Track_Order, #Cancel_Subscription

  • Entities = contextual details (nouns/metadata) that complete intent meaning

Example Utterance:
“What is the status of order #98723?”

  • Intent → #Track_Order
  • Entity → @OrderNumber = 98723
  • 🎯 Intent: #Track_Order
  • 🏷️ Entity: @OrderNumber=98723
  • ✅ Combined for dialogue decision

Slide 2: Multi-Turn Dialogue & Slot Filling

  1. Simple Q&A
    Immediate response from recognized intent

  2. Conditioned Responses
    Output changes using entities/rules
    Example: if @AccountType == "Checking", return checking-specific response

  3. Slot Filling
    Gather all required fields before API execution

Slide 3: Basic Error Management

Confidence Thresholds ((P_{intent}))

  • (P ) → Execute intent response directly
  • (0.40 P < 0.75) → Ask for confirmation/disambiguation
  • (P < 0.40) → Trigger fallback recovery node

Two-Strikes Rule

If the assistant fails to understand two consecutive turns, immediately:

  • move to robust fallback, or
  • transfer to a human agent
  • 🟢 High confidence: answer directly
  • 🟡 Medium confidence: clarify
  • 🔴 Low confidence: fallback
  • 🧑‍💼 Two failures: handoff to human
