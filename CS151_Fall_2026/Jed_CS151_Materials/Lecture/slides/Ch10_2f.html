Problem 1: Set Tracing

Looking at the sets:

evens = { 0, 2, 4, 6, 8 }
odds = { 1, 3, 5, 7, 9 }
primes = { 2, 3, 5, 7 }
squares = { 0, 1, 4, 9 }

What is the set C resulting from:

A = primes.intersection(evens)
B = odds.intersection(squares)
C = A.union(B)
  1. ∅
  2. { 1, 2, 9 }
  3. { 1, 3, 4, 5}
  4. { 0, 3, 4, 5, 7}
