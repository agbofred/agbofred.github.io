# Project 3 Rubric

* Flipping Horizontal
	* [ ] Properly flips
* Rotating
	* [ ] Pressing rotate left or right 4 times is succession returns to the original image
	* [ ] Pressing rotate left and then rotate right returns to the original image
	* [ ] Pressing rotate left or rotate right twice is undone by then pressing flip vertical and flip horizontal
* Grayscale
	* [ ] Properly converts to grayscale
* Green Screen
	* [ ] Works with Falcon image and then Rey
	* [ ] Works with Starry Night image and then Rey (Rey bigger than background)
	* [ ] Works with Countryside image and then Rey (Rey smaller than background)
	* [ ] CODE CHECK: Correctly compares pixel colors for ignoring a range of greens
* Equalize
	* [ ] Works correctly with Countryside (just by visual inspection)
		* [ ] Takes a reasonable amount of time to run (less than 10-15 seconds)
	* [ ] Works correctly with included ContrastTest.png
		* Top numbers black
		* Bottom numbers white
	* [ ] If you can easily check something like a cumulative histogram function, it is a nice check to make. Some people don't separate it out though unfortunately.
* Alterations
	* I don't really check any of the constants here, as their code generally doesn't touch them or interact with the interface
* Other Checks
	* [ ] Defined functions have at least simple docstrings describing them?
* Extensions
	* Many will include extensions from the contents of what you went over in section. I scored these sort-of as "half-extensions", since they are just largely copying over code from the sections slides (but it is still nice to see them incorporating extra stuff).
